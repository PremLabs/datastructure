Heaps & Priority Queues

A heap is a complete binary tree in which every parent is smaller than or equal to its children (a min-heap) or larger (a max-heap). It gives instant access to the minimum or maximum and is the standard implementation of a priority queue.

  • Level: Intermediate
  • Read time: 11 min
  • Push / pop: O(log n)
  • Peek min: O(1)

What is a heap?

A hospital emergency room does not treat patients in arrival order; it treats the most urgent first. A priority queue models that: you add items with priorities and always remove the most important one. A heap is the data structure that makes this efficient.

A heap has two properties:

  1. Shape: it is a complete binary tree. Every level is full except possibly the last, which fills from the left.
  2. Order: in a min-heap every parent is ≤ its children. The smallest value is therefore always at the root.

A heap is not fully sorted. Siblings have no particular order. That looseness is what makes it cheaper to maintain than a sorted array or a search tree.

Try it: tree view and array view

Insert the value 2 and watch it climb to the root. Then extract the minimum. Keep an eye on the array below the tree: it is the real storage.

A tree stored in an array

Because the tree is complete, it can be written level by level into an array with no gaps, and the parent–child links become arithmetic. For the node at index i:

RelationIndex
Left child2i + 1
Right child2i + 2
Parent(i − 1) / 2, rounded down

No node objects, no pointers. This compact layout is why heaps are fast in practice.

How the operations work

Insert (sift up)

Append the new value at the end of the array, which is the next free position in the tree. Then, while it is smaller than its parent, swap the two. It rises at most one level per swap, and a complete tree with n nodes has about log₂ n levels, so insertion is O(log n).

Extract min (sift down)

The minimum is at index 0. Take it, move the last element to the root to keep the shape complete, then repeatedly swap it with its smaller child until neither child is smaller. Also O(log n).

Build a heap in O(n)

Inserting n items one by one costs O(n log n). The heapify procedure does better: start from the last parent and sift down each node, working back to the root. Most nodes are near the bottom and move very little, and the total comes to O(n).

What heaps are used for

  • Priority queues: job schedulers, event simulations, rate limiters.
  • Top-k problems: keep a min-heap of size k while scanning; anything smaller than its root is discarded. O(n log k).
  • Dijkstra's shortest path and Prim's minimum spanning tree pull the closest unvisited vertex from a heap.
  • Heap sort: build a max-heap, then repeatedly move the root to the end. O(n log n) time, O(1) extra space.
  • Merging k sorted lists and finding a running median with two heaps.

Heaps & Priority Queues in Python, Java and JavaScript

Every sample below runs as is and prints the results shown in its comments. Switch language with the tabs; your choice is remembered on every page.

import heapq


class MinHeap:
    def __init__(self):
        self._a = []

    def push(self, value):                # O(log n)
        self._a.append(value)
        self._sift_up(len(self._a) - 1)

    def pop(self):                        # O(log n): remove the minimum
        if not self._a:
            raise IndexError("pop from empty heap")
        top = self._a[0]
        last = self._a.pop()
        if self._a:
            self._a[0] = last
            self._sift_down(0)
        return top

    def peek(self):                       # O(1)
        return self._a[0]

    def _sift_up(self, i):
        while i > 0:
            parent = (i - 1) // 2
            if self._a[parent] <= self._a[i]:
                break
            self._a[parent], self._a[i] = self._a[i], self._a[parent]
            i = parent

    def _sift_down(self, i):
        n = len(self._a)
        while True:
            smallest, left, right = i, 2 * i + 1, 2 * i + 2
            if left < n and self._a[left] < self._a[smallest]:
                smallest = left
            if right < n and self._a[right] < self._a[smallest]:
                smallest = right
            if smallest == i:
                return
            self._a[smallest], self._a[i] = self._a[i], self._a[smallest]
            i = smallest


heap = MinHeap()
for v in (8, 3, 14, 5, 9):
    heap.push(v)
print([heap.pop() for _ in range(5)])     # [3, 5, 8, 9, 14]

nums = [8, 3, 14, 5, 9]
heapq.heapify(nums)                       # O(n)
print(heapq.heappop(nums), heapq.nlargest(2, nums))   # 3 [14, 9]
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;
import java.util.PriorityQueue;

public class MinHeap {
    private final List<Integer> a = new ArrayList<>();

    public void push(int value) {                      // O(log n)
        a.add(value);
        siftUp(a.size() - 1);
    }

    public int pop() {                                 // O(log n): remove the minimum
        if (a.isEmpty()) throw new IllegalStateException("pop from empty heap");
        int top = a.get(0);
        int last = a.remove(a.size() - 1);
        if (!a.isEmpty()) {
            a.set(0, last);
            siftDown(0);
        }
        return top;
    }

    public int peek() { return a.get(0); }             // O(1)

    private void siftUp(int i) {
        while (i > 0) {
            int parent = (i - 1) / 2;
            if (a.get(parent) <= a.get(i)) break;
            Collections.swap(a, parent, i);
            i = parent;
        }
    }

    private void siftDown(int i) {
        int n = a.size();
        while (true) {
            int smallest = i, left = 2 * i + 1, right = 2 * i + 2;
            if (left < n && a.get(left) < a.get(smallest)) smallest = left;
            if (right < n && a.get(right) < a.get(smallest)) smallest = right;
            if (smallest == i) return;
            Collections.swap(a, smallest, i);
            i = smallest;
        }
    }

    public static void main(String[] args) {
        MinHeap heap = new MinHeap();
        for (int v : new int[]{8, 3, 14, 5, 9}) heap.push(v);
        for (int i = 0; i < 5; i++) System.out.print(heap.pop() + " ");   // 3 5 8 9 14
        System.out.println();

        // In practice, use the standard library:
        PriorityQueue<Integer> pq = new PriorityQueue<>(List.of(8, 3, 14, 5, 9));
        System.out.println(pq.poll());                                    // 3
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());
        maxHeap.addAll(List.of(8, 3, 14));
        System.out.println(maxHeap.peek());                               // 14
    }
}

class MinHeap {
  #a = [];

  get size() { return this.#a.length; }
  peek() { return this.#a[0]; }                    // O(1)

  push(value) {                                    // O(log n)
    this.#a.push(value);
    this.#siftUp(this.#a.length - 1);
  }

  pop() {                                          // O(log n): remove the minimum
    if (this.#a.length === 0) throw new Error('pop from empty heap');
    const top = this.#a[0];
    const last = this.#a.pop();
    if (this.#a.length > 0) {
      this.#a[0] = last;
      this.#siftDown(0);
    }
    return top;
  }

  #siftUp(i) {
    const a = this.#a;
    while (i > 0) {
      const parent = (i - 1) >> 1;
      if (a[parent] <= a[i]) break;
      [a[parent], a[i]] = [a[i], a[parent]];
      i = parent;
    }
  }

  #siftDown(i) {
    const a = this.#a, n = a.length;
    for (;;) {
      let smallest = i;
      const left = 2 * i + 1, right = 2 * i + 2;
      if (left < n && a[left] < a[smallest]) smallest = left;
      if (right < n && a[right] < a[smallest]) smallest = right;
      if (smallest === i) return;
      [a[smallest], a[i]] = [a[i], a[smallest]];
      i = smallest;
    }
  }
}

When to use it

Use a heap when

  • You repeatedly need the smallest or largest item.
  • You need the top k of a large or streaming data set.
  • You are implementing a scheduler or a graph algorithm such as Dijkstra's.

Look elsewhere when

  • You need to search for arbitrary values or iterate in sorted order (use a balanced BST).
  • Plain arrival order is enough (use a queue).

Common mistakes

  • Expecting the heap array to be sorted. Only the root is guaranteed.
  • Sifting down by swapping with either child instead of the smaller one (min-heap), which breaks the order.
  • Forgetting that Python's heapq and Java's PriorityQueue are min-heaps by default. For a max-heap, negate the values in Python or pass Collections.reverseOrder() in Java.
  • Mixing 0-based and 1-based index formulas.

Interview questions

Classic problems built on this topic, with the approach to each. Try them yourself before opening the hint.

Find the k-th largest element in an array.

Maintain a min-heap of size k; its root is the answer. O(n log k).

Merge k sorted lists.

Put the head of each list in a min-heap; pop the smallest and push its successor. O(n log k).

Find the median of a data stream.

A max-heap for the lower half and a min-heap for the upper half, kept within one element of each other in size.

Return the k most frequent elements.

Count with a hash map, then keep a size-k min-heap keyed on frequency.

Why is building a heap O(n) and not O(n log n)?

Sift-down cost is proportional to a node's height, and most nodes are near the bottom with small heights. The sum over all nodes is linear.

Frequently asked questions

What is the difference between a heap and a binary search tree?

A BST keeps all keys fully ordered (left < node < right) and supports searching for any key. A heap only guarantees that each parent beats its children, which is enough to find the minimum or maximum quickly and cheaper to maintain.

What is the difference between a min-heap and a max-heap?

In a min-heap each parent is smaller than or equal to its children, so the root is the minimum. In a max-heap each parent is larger, so the root is the maximum.

Is a priority queue the same as a heap?

A priority queue is the abstract behaviour: remove the highest-priority item first. A heap is the data structure normally used to implement it.
