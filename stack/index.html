Stacks

A stack is a collection where you add and remove items from the same end, so the most recently added item is always the first to come out: last in, first out (LIFO).

  • Level: Beginner
  • Read time: 7 min
  • Push / pop: O(1)
  • Order: LIFO

What is a stack?

A stack of plates is the standard picture, and it is accurate. You put a plate on top; you take a plate from the top. The plate at the bottom has been there longest and will be the last to go. A stack allows only three things:

  • push: put an item on top
  • pop: remove and return the top item
  • peek: look at the top item without removing it

That restriction is the point. Because you never touch anything but the top, every operation is O(1), and the structure naturally remembers things in reverse order of arrival.

Try it: push and pop

Push three different values, then pop three times. They come back in reverse.

How a stack is implemented

A stack is an abstract data type: it describes behaviour, not storage. The usual backing store is a dynamic array, with the top of the stack at the end, because appending and removing at the end of an array are both O(1). A linked list with push and pop at the head works equally well.

In practice you rarely write your own: Python uses a list (append/pop), Java uses ArrayDeque (the older Stack class is synchronised and best avoided), and JavaScript uses an Array (push/pop).

Where stacks appear

  • The call stack. Every function call pushes a frame holding its local variables and return address. Returning pops it. A recursion that never stops overflows this stack, which is where the term stack overflow comes from.
  • Undo and back buttons. Each action is pushed; undo pops the latest one.
  • Parsing. Matching brackets, evaluating expressions and parsing HTML all rely on "the most recently opened thing must close first".
  • Depth-first search. DFS on a graph or tree uses a stack, explicit or via recursion.

Worked example: balanced brackets

Scan the text left to right. Push every opening bracket. On a closing bracket, pop and check that it matches. If the stack is empty too early, or not empty at the end, the brackets are unbalanced. The code below implements this in all three languages.

Stacks in Python, Java and JavaScript

Every sample below runs as is and prints the results shown in its comments. Switch language with the tabs; your choice is remembered on every page.

class Stack:
    def __init__(self):
        self._items = []

    def push(self, value):                # O(1) amortised
        self._items.append(value)

    def pop(self):                        # O(1)
        if not self._items:
            raise IndexError("pop from empty stack")
        return self._items.pop()

    def peek(self):                       # O(1)
        if not self._items:
            raise IndexError("peek at empty stack")
        return self._items[-1]

    def is_empty(self):
        return not self._items


def is_balanced(text):
    """Classic stack problem: are the brackets in text balanced?"""
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = Stack()
    for ch in text:
        if ch in "([{":
            stack.push(ch)
        elif ch in pairs:
            if stack.is_empty() or stack.pop() != pairs[ch]:
                return False
    return stack.is_empty()


print(is_balanced("{[()]}"))              # True
print(is_balanced("([)]"))                # False
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.Map;

public class StackDemo {
    // In Java, prefer ArrayDeque over the legacy java.util.Stack class.
    static boolean isBalanced(String text) {
        Map<Character, Character> pairs = Map.of(')', '(', ']', '[', '}', '{');
        Deque<Character> stack = new ArrayDeque<>();
        for (char ch : text.toCharArray()) {
            if (ch == '(' || ch == '[' || ch == '{') {
                stack.push(ch);                            // O(1)
            } else if (pairs.containsKey(ch)) {
                if (stack.isEmpty() || stack.pop() != pairs.get(ch)) return false;
            }
        }
        return stack.isEmpty();
    }

    public static void main(String[] args) {
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(4); stack.push(9); stack.push(2);
        System.out.println(stack.peek());                  // 2
        System.out.println(stack.pop());                   // 2
        System.out.println(stack.pop());                   // 9

        System.out.println(isBalanced("{[()]}"));          // true
        System.out.println(isBalanced("([)]"));            // false
    }
}
class Stack {
  #items = [];

  push(value) { this.#items.push(value); }        // O(1) amortised

  pop() {                                         // O(1)
    if (this.isEmpty()) throw new Error('pop from empty stack');
    return this.#items.pop();
  }

  peek() {                                        // O(1)
    if (this.isEmpty()) throw new Error('peek at empty stack');
    return this.#items[this.#items.length - 1];
  }

  isEmpty() { return this.#items.length === 0; }
}

// Classic stack problem: are the brackets in text balanced?
function isBalanced(text) {
  const pairs = { ')': '(', ']': '[', '}': '{' };
  const stack = new Stack();
  for (const ch of text) {
    if ('([{'.includes(ch)) stack.push(ch);
    else if (ch in pairs) {
      if (stack.isEmpty() || stack.pop() !== pairs[ch]) return false;
    }
  }
  return stack.isEmpty();
}

console.log(isBalanced('{[()]}'));                // true
console.log(isBalanced('([)]'));                  // false

When to use it

Use a stack when

  • The most recent item must be handled first.
  • You need to reverse an order or backtrack.
  • You are converting recursion to iteration.

Look elsewhere when

  • Items must be processed in arrival order (use a queue).
  • You need the smallest or largest item (use a heap).

Common mistakes

  • Popping or peeking an empty stack. Check first.
  • Using Java's legacy Stack class in new code instead of ArrayDeque.
  • Deep recursion on large inputs in Python or JavaScript, which have limited call stacks. Use an explicit stack.

Frequently asked questions

What does LIFO mean?

Last in, first out. The item added most recently is the first one removed, like the top plate on a pile.

What is the difference between a stack and a queue?

A stack removes the newest item (LIFO). A queue removes the oldest item (FIFO).

What causes a stack overflow?

The call stack running out of space, usually because a recursive function calls itself too many times without reaching its base case.
