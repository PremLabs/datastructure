Arrays

An array stores items side by side in one block of memory, each reachable by its index in constant time. It is the simplest data structure and the one most others are built on.

  • Level: Beginner
  • Read time: 9 min
  • Access: O(1)
  • Insert / delete: O(n)

What is an array?

Picture a row of numbered lockers. Every locker is the same size, they sit next to each other, and if you know the number you can walk straight to it. An array works the same way: the elements occupy consecutive memory locations, so the address of element i is simply start + i × element_size. One multiplication and one addition, regardless of how long the array is. That is why reading a[500000] is exactly as fast as reading a[0].

The same layout is the source of the array's weakness. Because there are no gaps, putting a new element in the middle means moving everything after it one place to the right. Removing one means closing the gap.

Try it: insert, delete, access, search

Insert a value at index 0 and count the shifts. Then insert at the last index and compare.

How the operations work

Access by index: O(1)

The position is calculated, not searched for. This is called random access and it is the reason arrays are the default choice whenever you need the k-th item.

Search: O(n), or O(log n) if sorted

Without any ordering you can only check the elements one by one (linear search). If the array is sorted, binary search finds an element in O(log n).

Insert and delete: O(n)

Inserting at index i shifts n − i elements. At the end that is zero shifts; at the front it is all of them. Deleting works the same way in the other direction.

Static and dynamic arrays

A static array has a fixed size chosen when it is created (a Java int[]). A dynamic array (Python list, Java ArrayList, JavaScript Array) grows automatically: when the block is full it allocates a larger one, usually double the size, and copies everything across. That copy is O(n), but it happens so rarely that appending costs O(1) amortised. The code below implements exactly this.

Arrays in Python, Java and JavaScript

class DynamicArray:
    """A growable array built on a fixed-size block, like Python's list."""

    def __init__(self):
        self._capacity = 2
        self._size = 0
        self._data = [None] * self._capacity

    def __len__(self):
        return self._size

    def get(self, index):                 # O(1)
        if not 0 <= index < self._size:
            raise IndexError("index out of range")
        return self._data[index]

    def append(self, value):              # O(1) amortised
        if self._size == self._capacity:
            self._resize(self._capacity * 2)
        self._data[self._size] = value
        self._size += 1

    def insert(self, index, value):       # O(n): shifts the tail right
        if not 0 <= index <= self._size:
            raise IndexError("index out of range")
        if self._size == self._capacity:
            self._resize(self._capacity * 2)
        for i in range(self._size, index, -1):
            self._data[i] = self._data[i - 1]
        self._data[index] = value
        self._size += 1

    def remove_at(self, index):           # O(n): shifts the tail left
        value = self.get(index)
        for i in range(index, self._size - 1):
            self._data[i] = self._data[i + 1]
        self._size -= 1
        self._data[self._size] = None
        return value

    def _resize(self, capacity):          # O(n) copy, but rare
        new_data = [None] * capacity
        for i in range(self._size):
            new_data[i] = self._data[i]
        self._data, self._capacity = new_data, capacity

import java.util.Arrays;

public class DynamicArray {
    private int[] data = new int[2];
    private int size = 0;

    public int size() { return size; }

    public int get(int index) {                    // O(1)
        if (index < 0 || index >= size) throw new IndexOutOfBoundsException();
        return data[index];
    }

    public void append(int value) {                // O(1) amortised
        if (size == data.length) resize(data.length * 2);
        data[size++] = value;
    }

    public void insert(int index, int value) {     // O(n): shifts the tail right
        if (index < 0 || index > size) throw new IndexOutOfBoundsException();
        if (size == data.length) resize(data.length * 2);
        for (int i = size; i > index; i--) data[i] = data[i - 1];
        data[index] = value;
        size++;
    }

    public int removeAt(int index) {               // O(n): shifts the tail left
        int value = get(index);
        for (int i = index; i < size - 1; i++) data[i] = data[i + 1];
        size--;
        return value;
    }

    private void resize(int capacity) {            // O(n) copy, but rare
        data = Arrays.copyOf(data, capacity);
    }

    public static void main(String[] args) {
        DynamicArray arr = new DynamicArray();
        arr.append(12); arr.append(45); arr.append(7);
        arr.insert(1, 30);                         // 12, 30, 45, 7
        arr.removeAt(0);                           // 30, 45, 7
        for (int i = 0; i < arr.size(); i++) System.out.print(arr.get(i) + " ");
    }
}

class DynamicArray {
  #data = new Array(2);
  #size = 0;

  get length() { return this.#size; }

  get(index) {                             // O(1)
    if (index < 0 || index >= this.#size) throw new RangeError('index out of range');
    return this.#data[index];
  }

  append(value) {                          // O(1) amortised
    if (this.#size === this.#data.length) this.#resize(this.#data.length * 2);
    this.#data[this.#size++] = value;
  }

  insert(index, value) {                   // O(n): shifts the tail right
    if (index < 0 || index > this.#size) throw new RangeError('index out of range');
    if (this.#size === this.#data.length) this.#resize(this.#data.length * 2);
    for (let i = this.#size; i > index; i--) this.#data[i] = this.#data[i - 1];
    this.#data[index] = value;
    this.#size++;
  }

  removeAt(index) {                        // O(n): shifts the tail left
    const value = this.get(index);
    for (let i = index; i < this.#size - 1; i++) this.#data[i] = this.#data[i + 1];
    this.#size--;
    return value;
  }

  #resize(capacity) {                      // O(n) copy, but rare
    const next = new Array(capacity);
    for (let i = 0; i < this.#size; i++) next[i] = this.#data[i];
    this.#data = next;
  }
}

When to use it

Use an array when

  • You need fast access by position.
  • You mostly add and remove at the end.
  • You iterate over all elements often: contiguous memory is very cache-friendly.
  • The data is sorted and you want binary search.

Look elsewhere when

  • You insert or delete at the front or middle constantly (consider a linked list or deque).
  • You look items up by key rather than position (use a hash table).

Common mistakes

  • Off-by-one errors: valid indexes run from 0 to length − 1.
  • Removing items from an array while looping forward over it, which skips elements. Loop backwards or build a new array.
  • Using insert(0, x) or shift() inside a loop, turning an O(n) routine into O(n²).
  • Assuming two variables hold separate arrays when they reference the same one.

Interview questions

Classic problems built on this topic, with the approach to each. Try them yourself before opening the hint.

Find two numbers in an array that add up to a target.

One pass with a hash set of numbers seen so far: O(n) time, O(n) space. If sorted, use two pointers from each end for O(1) space.

Rotate an array by k positions in place.

Reverse the whole array, then reverse the first k elements and the remaining n − k.

Find the maximum sum of a contiguous subarray.

Kadane's algorithm: keep the best sum ending at the current index; reset to the current element when the running sum would be lower.

Remove duplicates from a sorted array in place.

Two pointers: one reads, one writes each new distinct value.

Why is appending to a dynamic array O(1) amortised?

Doubling means n appends cause copies of 1 + 2 + 4 + … + n ≈ 2n elements in total, which is O(1) per append on average.

Frequently asked questions

What is the difference between an array and a list?

An array is a fixed block of same-sized slots. What Python calls a list and Java calls an ArrayList is a dynamic array: an array that reallocates itself to grow. A linked list is a different structure entirely.

Why does array indexing start at 0?

The index is an offset from the start of the block. The first element is zero steps from the start, so its address is start + 0 × size.

Is inserting into an array always slow?

No. Appending at the end is O(1) amortised. Only inserting near the front is expensive, because everything after the insertion point has to move.
