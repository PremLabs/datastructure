Queues

A queue adds items at one end and removes them from the other, so items leave in the order they arrived: first in, first out (FIFO).

  • Level: Beginner
  • Read time: 8 min
  • Enqueue / dequeue: O(1)
  • Order: FIFO

What is a queue?

A queue behaves like a line at a ticket counter. New people join at the back (the rear) and the person at the front is served next. Nobody skips ahead. The operations are:

  • enqueue: add an item at the rear
  • dequeue: remove and return the item at the front
  • peek: look at the front item

Queues appear wherever work arrives faster than it can be handled and fairness matters: request handling in a web server, tasks handed to a thread pool, messages in Kafka or RabbitMQ, and breadth-first search.

Try it: enqueue and dequeue

Enqueue a few values and dequeue them. They leave in the order they joined.

How a queue is implemented

The obvious approach, an array where you remove from index 0, is a trap: removing the first element shifts all the others, so each dequeue costs O(n). Python's list.pop(0) and JavaScript's array.shift() both have this cost. There are two proper solutions.

Linked list or deque

Keep pointers to both ends. Enqueue at the tail, dequeue at the head, both O(1). Python's collections.deque and Java's ArrayDeque give you this ready-made.

Circular queue (ring buffer)

Use a fixed array and two positions, head and size. Instead of shifting elements, move head forward. When an index reaches the end of the array it wraps around to 0 with the modulo operator: (head + size) % capacity. Nothing is ever moved, and the memory is reused indefinitely. Ring buffers are used for audio streams, network packets and logging where a bounded, allocation-free queue is needed.

Variants

  • Deque (double-ended queue): add and remove at both ends in O(1). It can act as a stack or a queue.
  • Priority queue: the item with the highest priority leaves first, regardless of arrival order. It is implemented with a heap.
  • Blocking queue: dequeue waits when empty and enqueue waits when full. This is the standard way to pass work between threads.

Queues in Python, Java and JavaScript

Every sample below runs as is and prints the results shown in its comments. Switch language with the tabs; your choice is remembered on every page.

from collections import deque


class Queue:
    """FIFO queue. deque gives O(1) at both ends; list.pop(0) would be O(n)."""

    def __init__(self):
        self._items = deque()

    def enqueue(self, value):             # O(1)
        self._items.append(value)

    def dequeue(self):                    # O(1)
        if not self._items:
            raise IndexError("dequeue from empty queue")
        return self._items.popleft()

    def peek(self):                       # O(1)
        return self._items[0]

    def __len__(self):
        return len(self._items)


class CircularQueue:
    """Fixed-capacity queue on a plain array: the ring buffer."""

    def __init__(self, capacity):
        self._data = [None] * capacity
        self._head = 0
        self._size = 0

    def enqueue(self, value):
        if self._size == len(self._data):
            raise OverflowError("queue is full")
        tail = (self._head + self._size) % len(self._data)
        self._data[tail] = value
        self._size += 1

    def dequeue(self):
        if self._size == 0:
            raise IndexError("queue is empty")
        value = self._data[self._head]
        self._head = (self._head + 1) % len(self._data)
        self._size -= 1
        return value

for job in ("print", "email", "backup"):

import java.util.ArrayDeque;
import java.util.Queue;

public class QueueDemo {
    /** Fixed-capacity queue on a plain array: the ring buffer. */
    static class CircularQueue {
        private final int[] data;
        private int head = 0, size = 0;

        CircularQueue(int capacity) { data = new int[capacity]; }

        void enqueue(int value) {                          // O(1)
            if (size == data.length) throw new IllegalStateException("queue is full");
            data[(head + size) % data.length] = value;
            size++;
        }

        int dequeue() {                                    // O(1)
            if (size == 0) throw new IllegalStateException("queue is empty");
            int value = data[head];
            head = (head + 1) % data.length;
            size--;
            return value;
        }
    }

    public static void main(String[] args) {
        Queue<String> q = new ArrayDeque<>();              // the standard FIFO queue
        q.offer("print"); q.offer("email"); q.offer("backup");
        System.out.println(q.poll() + " " + q.poll());     // print email

        CircularQueue ring = new CircularQueue(3);
        ring.enqueue(1); ring.enqueue(2); ring.dequeue(); ring.enqueue(3); ring.enqueue(4);
        System.out.println(ring.dequeue() + " " + ring.dequeue() + " " + ring.dequeue()); // 2 3 4
    }
}
// Array.prototype.shift() is O(n), so a real queue keeps a moving head index instead.
class Queue {
  #items = [];
  #head = 0;

  enqueue(value) { this.#items.push(value); }     // O(1)

  dequeue() {                                     // O(1) amortised
    if (this.length === 0) throw new Error('dequeue from empty queue');
    const value = this.#items[this.#head++];
    if (this.#head > 32 && this.#head * 2 > this.#items.length) {
      this.#items = this.#items.slice(this.#head); // drop the used-up front
      this.#head = 0;
    }
    return value;
  }

  peek() { return this.#items[this.#head]; }
  get length() { return this.#items.length - this.#head; }
}

// Fixed-capacity queue on a plain array: the ring buffer.
class CircularQueue {
  #data; #head = 0; #size = 0;
  constructor(capacity) { this.#data = new Array(capacity); }

  enqueue(value) {
    if (this.#size === this.#data.length) throw new Error('queue is full');
    this.#data[(this.#head + this.#size) % this.#data.length] = value;
    this.#size++;
  }

  dequeue() {
    if (this.#size === 0) throw new Error('queue is empty');
    const value = this.#data[this.#head];
    this.#head = (this.#head + 1) % this.#data.length;
    this.#size--;
    return value;
  }
}

const q = new Queue();
['print', 'email', 'backup'].forEach(job => q.enqueue(job));
console.log(q.dequeue(), q.dequeue());            // print email

const ring = new CircularQueue(3);
ring.enqueue(1); ring.enqueue(2); ring.dequeue(); ring.enqueue(3); ring.enqueue(4);
console.log(ring.dequeue(), ring.dequeue(), ring.dequeue()); // 2 3 4

When to use it

Use a queue when

  • Work must be handled in arrival order.
  • You are doing breadth-first search or level-order traversal.
  • A producer and a consumer run at different speeds and need a buffer.

Look elsewhere when

  • The newest item should go first (use a stack).
  • Some items are more urgent than others (use a priority queue).

Common mistakes

  • Dequeuing with list.pop(0) or array.shift() in a loop: O(n²) overall.
  • Off-by-one errors in ring buffers when telling full from empty. Tracking size explicitly, as in the code above, avoids the ambiguity.
  • Letting an unbounded queue grow until memory runs out when the consumer is slower than the producer.

Interview questions

Classic problems built on this topic, with the approach to each. Try them yourself before opening the hint.

Implement a queue using two stacks.

Enqueue pushes onto stack A. Dequeue pops from stack B, refilling B from A only when B is empty. Amortised O(1).

Design a circular queue.

Fixed array plus head and size; compute the tail as (head + size) % capacity. Shown above.

Find the maximum in every sliding window of size k.

A deque of indexes kept in decreasing order of value; the front is always the window maximum. O(n).

Why is BFS implemented with a queue?

A queue processes nodes in the order they were discovered, which is in order of distance from the start.

Frequently asked questions

What does FIFO mean?

First in, first out. The item that has been waiting longest is the next one removed.

What is a circular queue?

A queue stored in a fixed-size array where the positions wrap around to the beginning when they reach the end, so freed slots are reused without moving any elements.

What is the difference between a queue and a deque?

A queue adds at one end and removes at the other. A deque (double-ended queue) can add and remove at both ends.
