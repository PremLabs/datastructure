Graphs: BFS & DFS

A graph is a set of vertices (nodes) joined by edges. It is the most general data structure in this series: trees and linked lists are special cases, and maps, social networks and dependency systems are all graphs.

  • Level: Intermediate
  • Read time: 13 min
  • BFS / DFS: O(V + E)
  • Space: O(V)

What is a graph?

Whenever you have things and relationships between pairs of them, you have a graph. Cities and roads. People and friendships. Web pages and links. Tasks and their dependencies.

TermMeaningExample
Vertex (node)An itemA city
EdgeA connection between two verticesA road
UndirectedEdges go both waysFriendship
DirectedEdges have a direction"Follows" on social media
WeightedEdges carry a costRoad distance
CycleA path that returns to its startA ring road

Unlike a tree, a graph has no root, may contain cycles, and may be in several disconnected pieces. Every graph algorithm therefore has to remember which vertices it has already visited, or it will go round in circles.

Try it: BFS versus DFS

Run both from node A and compare the visiting order. BFS spreads outward in rings; DFS dives down one path and backtracks.

How to store a graph

Adjacency list

A map from each vertex to the list of its neighbours. Memory is O(V + E), and iterating over a vertex's neighbours takes time proportional to how many it has. This is the default choice, because most real graphs are sparse.

Adjacency matrix

A V × V grid where cell (i, j) says whether an edge exists. Checking a specific edge is O(1), but memory is O(V²) and listing neighbours is O(V). It suits small or dense graphs.

Breadth-first search (BFS)

BFS explores in layers: the start vertex, then everything one edge away, then two edges away. It uses a queue.

  1. Put the start vertex in the queue and mark it visited.
  2. Dequeue a vertex. For each unvisited neighbour: mark it and enqueue it.
  3. Repeat until the queue is empty.

Because vertices are reached in order of distance, BFS finds the shortest path in an unweighted graph. Record each vertex's parent as you discover it, and you can walk back from the goal to reconstruct the route, as shortest_path does in the code below.

Depth-first search (DFS)

DFS follows one path as far as it can, then backtracks to the most recent vertex with an unexplored neighbour. It uses a stack, most simply the call stack through recursion.

DFS is the basis for detecting cycles, topological sorting (ordering tasks so that each comes after its dependencies), finding connected components, and solving mazes and puzzles by backtracking.

BFS or DFS?

BFSDFS

For weighted graphs with non-negative weights, the shortest path needs Dijkstra's algorithm, which is BFS with the queue replaced by a priority queue.

Graphs: BFS & DFS in Python, Java and JavaScript

Every sample below runs as is and prints the results shown in its comments. Switch language with the tabs; your choice is remembered on every page.

from collections import deque


class Graph:
    """Undirected graph stored as an adjacency list."""

    def __init__(self):
        self.adj = {}

    def add_edge(self, u, v):
        self.adj.setdefault(u, []).append(v)
        self.adj.setdefault(v, []).append(u)

    def bfs(self, start):                 # O(V + E), uses a queue
        order, seen, queue = [], {start}, deque([start])
        while queue:
            node = queue.popleft()
            order.append(node)
            for nxt in self.adj[node]:
                if nxt not in seen:       # mark when queued, not when popped
                    seen.add(nxt)
                    queue.append(nxt)
        return order

    def dfs(self, start):                 # O(V + E), uses recursion
        order, seen = [], set()
        def visit(node):
            seen.add(node)
            order.append(node)
            for nxt in self.adj[node]:
                if nxt not in seen:
                    visit(nxt)
        visit(start)
        return order

    def shortest_path(self, start, goal):   # fewest edges, via BFS
        parent, queue = {start: None}, deque([start])
        while queue:
            node = queue.popleft()
            if node == goal:
                path = []
                while node is not None:
                    path.append(node)
                    node = parent[node]
                return path[::-1]
            for nxt in self.adj[node]:
                if nxt not in parent:
                    parent[nxt] = node
                    queue.append(nxt)
        return None


g = Graph()
for u, v in ["AB", "AD", "BC", "BE", "DE", "CF", "EG", "FG"]:
    g.add_edge(u, v)
print(g.bfs("A"))                 # ['A', 'B', 'D', 'C', 'E', 'F', 'G']
print(g.dfs("A"))                 # ['A', 'B', 'C', 'F', 'G', 'E', 'D']
print(g.shortest_path("A", "G"))  # ['A', 'B', 'E', 'G']
import java.util.*;

public class Graph {
    private final Map<String, List<String>> adj = new LinkedHashMap<>();

    public void addEdge(String u, String v) {              // undirected
        adj.computeIfAbsent(u, k -> new ArrayList<>()).add(v);
        adj.computeIfAbsent(v, k -> new ArrayList<>()).add(u);
    }

    public List<String> bfs(String start) {                // O(V + E), uses a queue
        List<String> order = new ArrayList<>();
        Set<String> seen = new HashSet<>(List.of(start));
        Queue<String> queue = new ArrayDeque<>(List.of(start));
        while (!queue.isEmpty()) {
            String node = queue.poll();
            order.add(node);
            for (String next : adj.get(node)) {
                if (seen.add(next)) queue.offer(next);     // mark when queued
            }
        }
        return order;
    }

    public List<String> dfs(String start) {                // O(V + E), uses recursion
        List<String> order = new ArrayList<>();
        visit(start, new HashSet<>(), order);
        return order;
    }

    private void visit(String node, Set<String> seen, List<String> order) {
        seen.add(node);
        order.add(node);
        for (String next : adj.get(node)) {
            if (!seen.contains(next)) visit(next, seen, order);
        }
    }

    public List<String> shortestPath(String start, String goal) {   // fewest edges, via BFS
        Map<String, String> parent = new HashMap<>();
        parent.put(start, null);
        Queue<String> queue = new ArrayDeque<>(List.of(start));
        while (!queue.isEmpty()) {
            String node = queue.poll();
            if (node.equals(goal)) {
                LinkedList<String> path = new LinkedList<>();
                for (String n = goal; n != null; n = parent.get(n)) path.addFirst(n);
                return path;
            }
            for (String next : adj.get(node)) {
                if (!parent.containsKey(next)) { parent.put(next, node); queue.offer(next); }
            }
        }
        return null;
    }

    public static void main(String[] args) {
        Graph g = new Graph();
        for (String e : new String[]{"AB", "AD", "BC", "BE", "DE", "CF", "EG", "FG"}) {
            g.addEdge(e.substring(0, 1), e.substring(1));
        }
        System.out.println(g.bfs("A"));                // [A, B, D, C, E, F, G]
        System.out.println(g.dfs("A"));                // [A, B, C, F, G, E, D]
        System.out.println(g.shortestPath("A", "G"));  // [A, B, E, G]
    }
}
class Graph {
  adj = new Map();                         // adjacency list

  addEdge(u, v) {                          // undirected
    if (!this.adj.has(u)) this.adj.set(u, []);
    if (!this.adj.has(v)) this.adj.set(v, []);
    this.adj.get(u).push(v);
    this.adj.get(v).push(u);
  }

  bfs(start) {                             // O(V + E), uses a queue
    const order = [], seen = new Set([start]), queue = [start];
    for (let head = 0; head < queue.length; head++) {
      const node = queue[head];
      order.push(node);
      for (const next of this.adj.get(node)) {
        if (!seen.has(next)) { seen.add(next); queue.push(next); }  // mark when queued
      }
    }
    return order;
  }

  dfs(start) {                             // O(V + E), uses recursion
    const order = [], seen = new Set();
    const visit = node => {
      seen.add(node);
      order.push(node);
      for (const next of this.adj.get(node)) if (!seen.has(next)) visit(next);
    };
    visit(start);
    return order;
  }

  shortestPath(start, goal) {              // fewest edges, via BFS
    const parent = new Map([[start, null]]), queue = [start];
    for (let head = 0; head < queue.length; head++) {
      const node = queue[head];
      if (node === goal) {
        const path = [];
        for (let n = goal; n !== null; n = parent.get(n)) path.unshift(n);
        return path;
      }
      for (const next of this.adj.get(node)) {
        if (!parent.has(next)) { parent.set(next, node); queue.push(next); }
      }
    }
    return null;
  }
}

['AB', 'AD', 'BC', 'BE', 'DE', 'CF', 'EG', 'FG'].forEach(([u, v]) => g.addEdge(u, v));
console.log(g.bfs('A'));                   // A B D C E F G
console.log(g.dfs('A'));                   // A B C F G E D
console.log(g.shortestPath('A', 'G'));     // A B E G

When to use it

Use a graph when

  • Relationships between items matter as much as the items.
  • You need routes, reachability or dependencies.
  • The connections are many-to-many and may contain cycles.

Look elsewhere when

  • The data is strictly hierarchical with one parent per item (a tree is simpler).

Common mistakes

  • Not tracking visited vertices, causing an infinite loop on any cycle.
  • In BFS, marking a vertex visited when it is dequeued rather than when it is enqueued, so the same vertex is queued many times.
  • Adding only one direction of an undirected edge.
  • Using DFS to find a shortest path.
  • Assuming the graph is connected. Loop over all vertices and start a search from each unvisited one.

Interview questions

Classic problems built on this topic, with the approach to each. Try them yourself before opening the hint.

Count the number of islands in a grid.

Treat each land cell as a vertex connected to its four neighbours; run BFS or DFS from every unvisited land cell and count the searches.

Detect a cycle in a directed graph.

DFS with three states: unvisited, in the current path, finished. Reaching a vertex that is in the current path means a cycle.

Course schedule: can all courses be finished given prerequisites?

Topological sort. With Kahn's algorithm, repeatedly remove vertices with no incoming edges; if any remain, there is a cycle.

Find the shortest path in an unweighted graph or maze.

BFS, recording parents or distances.

Clone a graph.

Traverse with a hash map from each original vertex to its copy.

Frequently asked questions

What is the difference between BFS and DFS?

BFS visits vertices level by level using a queue and finds shortest paths in unweighted graphs. DFS follows one path as deep as possible using a stack or recursion before backtracking.

What is the difference between a graph and a tree?

A tree is a connected graph with no cycles and exactly one path between any two nodes. A general graph may have cycles, several components and no root.

Should I use an adjacency list or an adjacency matrix?

Use an adjacency list for most graphs: it needs O(V + E) memory and is fast to traverse. Use a matrix when the graph is dense or you need constant-time edge checks.
