Tries (Prefix Trees)

A trie, or prefix tree, stores strings character by character along the paths of a tree, so words with a common prefix share the same nodes. Looking up a word takes time proportional to its length, not to the number of words stored.

  • Level: Intermediate
  • Read time: 9 min
  • Insert / search: O(L)
  • L: word length

What is a trie?

Type "ca" into a search box and suggestions appear: car, cart, cat. A hash table cannot do this, because hashing "ca" says nothing about keys that merely start with "ca". A trie can.

In a trie each edge is labelled with a character. The root represents the empty string, and walking down from the root spells out a prefix. A node carries a flag saying whether a complete word ends there. That flag is necessary because one word can be a prefix of another: after inserting "cart", the path c → a → r exists whether or not "car" itself was inserted.

Try it: shared prefixes

The trie starts with car, cat, cart, do and dog. Insert "card" and see that only one new node is created. Then try Starts with on "ca".

How the operations work

Insert

Start at the root. For each character, follow the matching child, creating it if it does not exist. Mark the final node as the end of a word. Cost: O(L) for a word of length L.

Search

Follow the characters from the root. If a child is missing, the word is not present. If you reach the end, the answer is the node's end-of-word flag.

Starts with (prefix search)

The same walk, without checking the flag. If the path exists, at least one stored word begins with that prefix. Every word below that node is a completion, which is exactly what autocomplete collects.

Storing the children

  • Fixed array of 26 (for lowercase a–z): fastest lookup, but wastes memory when most slots are empty.
  • Hash map per node: flexible for any alphabet, including Unicode. Used in the Python and JavaScript code below.
  • Sorted map (Java TreeMap): results come out in alphabetical order for free.

Trade-offs

A trie's lookup time does not depend on how many words it holds, and it answers prefix questions that hashing cannot. The price is memory: one node per character, each with its own child container. A compressed trie (radix tree) merges chains of single-child nodes into one edge labelled with a whole substring; IP routing tables and some in-memory databases use that variant.

Tries (Prefix Trees) in Python, Java and JavaScript

Every sample below runs as is and prints the results shown in its comments. Switch language with the tabs; your choice is remembered on every page.

class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_word = False


class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word):               # O(L), L = len(word)
        node = self.root
        for ch in word:
            node = node.children.setdefault(ch, TrieNode())
        node.is_word = True

    def _find(self, prefix):
        node = self.root
        for ch in prefix:
            node = node.children.get(ch)
            if node is None:
                return None
        return node

    def search(self, word):               # O(L): whole word stored?
        node = self._find(word)
        return node is not None and node.is_word

    def starts_with(self, prefix):        # O(L): any word with this prefix?
        return self._find(prefix) is not None

    def autocomplete(self, prefix):       # every stored word under the prefix
        results = []
        def collect(node, path):
            if node.is_word:
                results.append(path)
            for ch in sorted(node.children):
                collect(node.children[ch], path + ch)
        start = self._find(prefix)
        if start:
            collect(start, prefix)
        return results


trie = Trie()
for word in ("car", "cat", "cart", "do", "dog"):
    trie.insert(word)
print(trie.search("car"), trie.search("ca"))   # True False
print(trie.starts_with("ca"))                  # True
print(trie.autocomplete("ca"))                 # ['car', 'cart', 'cat']
import java.util.ArrayList;
import java.util.List;
import java.util.Map;
import java.util.TreeMap;

public class Trie {
    private static class Node {
        Map<Character, Node> children = new TreeMap<>();   // TreeMap keeps letters sorted
        boolean isWord;
    }

    private final Node root = new Node();

    public void insert(String word) {                      // O(L), L = word length
        Node node = root;
        for (char ch : word.toCharArray()) {
            node = node.children.computeIfAbsent(ch, k -> new Node());
        }
        node.isWord = true;
    }

    private Node find(String prefix) {
        Node node = root;
        for (char ch : prefix.toCharArray()) {
            node = node.children.get(ch);
            if (node == null) return null;
        }
        return node;
    }

    public boolean search(String word) {                   // O(L): whole word stored?
        Node node = find(word);
        return node != null && node.isWord;
    }

    public boolean startsWith(String prefix) {             // O(L)
        return find(prefix) != null;
    }

    public List<String> autocomplete(String prefix) {      // every stored word under the prefix
        List<String> results = new ArrayList<>();
        Node start = find(prefix);
        if (start != null) collect(start, new StringBuilder(prefix), results);
        return results;
    }

    private void collect(Node node, StringBuilder path, List<String> results) {
        if (node.isWord) results.add(path.toString());
        for (Map.Entry<Character, Node> e : node.children.entrySet()) {
            path.append(e.getKey());
            collect(e.getValue(), path, results);
            path.deleteCharAt(path.length() - 1);          // backtrack
        }
    }

    public static void main(String[] args) {
        Trie trie = new Trie();
        for (String word : new String[]{"car", "cat", "cart", "do", "dog"}) trie.insert(word);
        System.out.println(trie.search("car") + " " + trie.search("ca"));  // true false
        System.out.println(trie.startsWith("ca"));                         // true
        System.out.println(trie.autocomplete("ca"));                       // [car, cart, cat]
    }
}
class TrieNode {
  children = new Map();
  isWord = false;
}

class Trie {
  root = new TrieNode();

  insert(word) {                           // O(L), L = word.length
    let node = this.root;
    for (const ch of word) {
      if (!node.children.has(ch)) node.children.set(ch, new TrieNode());
      node = node.children.get(ch);
    }
    node.isWord = true;
  }

  #find(prefix) {
    let node = this.root;
    for (const ch of prefix) {
      node = node.children.get(ch);
      if (!node) return null;
    }
    return node;
  }

  search(word) {                           // O(L): whole word stored?
    const node = this.#find(word);
    return node !== null && node.isWord;
  }

  startsWith(prefix) {                     // O(L)
    return this.#find(prefix) !== null;
  }

  autocomplete(prefix) {                   // every stored word under the prefix
    const results = [];
    const collect = (node, path) => {
      if (node.isWord) results.push(path);
      for (const ch of [...node.children.keys()].sort()) collect(node.children.get(ch), path + ch);
    };
    const start = this.#find(prefix);
    if (start) collect(start, prefix);
    return results;
  }
}

const trie = new Trie();
['car', 'cat', 'cart', 'do', 'dog'].forEach(word => trie.insert(word));
console.log(trie.search('car'), trie.search('ca'));  // true false
console.log(trie.startsWith('ca'));                  // true
console.log(trie.autocomplete('ca'));                // [ 'car', 'cart', 'cat' ]

When to use it

Use a trie when

  • You need autocomplete or type-ahead search.
  • You are building a spell checker or word game solver.
  • You match prefixes: IP routing, phone number lookup, command completion.

Look elsewhere when

  • You only need exact-match lookup (a hash set uses less memory).
  • Your keys are not sequences of symbols.

Common mistakes

  • Leaving out the end-of-word flag, so every prefix is reported as a word.
  • Treating search and startsWith as the same operation.
  • Deleting a word by removing nodes that other words still share. Clear the flag, and remove only nodes that have no children and end no word.
  • Allocating a 26-slot array per node for a large, sparse vocabulary.

Frequently asked questions

What is a trie used for?

Autocomplete, spell checking, prefix matching such as IP routing, and any task that asks which stored strings begin with a given prefix.

What is the difference between a trie and a hash table?

A hash table finds exact keys in O(1) on average but cannot search by prefix or return keys in order. A trie finds a key in O(L) and can list every key that shares a prefix.

How is trie pronounced?

Usually like 'try', to distinguish it from 'tree', though the name comes from the middle of the word retrieval.
