Binary Trees & Traversals

A binary tree is a hierarchy in which every node has at most two children, called left and right. Learning to traverse one is the foundation for search trees, heaps, and most recursive problem solving.

  • Level: Intermediate
  • Read time: 10 min
  • Traversal: O(n)
  • Space: O(h)

What is a binary tree?

Arrays and linked lists are linear: each item has one successor. Trees are hierarchical, like a family tree or a folder structure. A tree is made of nodes connected by edges, starting from a single root. In a binary tree each node has up to two children.

TermMeaning
RootThe top node, which has no parent
LeafA node with no children
Depth of a nodeNumber of edges from the root down to it
Height of a treeNumber of edges on the longest path from the root to a leaf
SubtreeA node together with all its descendants: itself a tree

That last row matters most. Every subtree is a smaller tree, so tree algorithms are naturally recursive: do something with the node, then solve the same problem for the left subtree and the right subtree.

Try it: four traversals of one tree

A traversal visits every node exactly once. The order is what distinguishes them. Run each and compare the output line.

The four traversals

Depth-first: in-order, pre-order, post-order

All three go as deep as possible before backing up. They differ only in when the node itself is processed relative to its children:

  • Pre-order (node, left, right): the parent comes before its children. Used to copy a tree or write it to a file.
  • In-order (left, node, right): on a binary search tree this yields the keys in sorted order.
  • Post-order (left, right, node): children come before the parent. Used to delete a tree, or to compute something that depends on the children first, such as the size of a folder.

In code the three functions are identical except for the position of one line. The recursion uses the call stack, so space is O(h) where h is the height.

Breadth-first: level-order

Visit the root, then all nodes at depth 1, then depth 2, and so on. This needs a queue: dequeue a node, process it, enqueue its children. Space is O(w) where w is the widest level, which can be n/2 for a full tree.

Tree shapes

  • Full: every node has zero or two children.
  • Complete: every level is full except possibly the last, which fills from the left. Heaps are complete trees.
  • Perfect: all leaves at the same depth; a perfect tree of height h has 2h+1 − 1 nodes.
  • Balanced: the height is O(log n). This is what keeps tree operations fast.
  • Degenerate: every node has one child. It is a linked list in disguise, with height n − 1.

Time complexity

OperationAverageWorstNotes
Any traversalO(n)O(n)Each node is visited once

Binary Trees & Traversals in Python, Java and JavaScript

Every sample below runs as is and prints the results shown in its comments. Switch language with the tabs; your choice is remembered on every page.

from collections import deque


class TreeNode:
    def __init__(self, value, left=None, right=None):
        self.value = value
        self.left = left
        self.right = right


def inorder(node, out):                   # left, node, right
    if node:
        inorder(node.left, out)
        out.append(node.value)
        inorder(node.right, out)
    return out

def preorder(node, out):                  # node, left, right
    if node:
        out.append(node.value)
        preorder(node.left, out)
        preorder(node.right, out)
    return out

def postorder(node, out):                 # left, right, node
    if node:
        postorder(node.left, out)
        postorder(node.right, out)
        out.append(node.value)
    return out

def level_order(root):                    # breadth-first, uses a queue
    out, queue = [], deque([root] if root else [])
    while queue:
        node = queue.popleft()
        out.append(node.value)
        if node.left:
            queue.append(node.left)
        if node.right:
            queue.append(node.right)
    return out

def height(node):                         # edges on the longest path down
    if node is None:
        return -1
    return 1 + max(height(node.left), height(node.right))


#         8
#       /   \
#      3     10
#     / \      \
#    1   6      14
#       / \    /
#      4   7  13
root = TreeNode(8,
                TreeNode(3, TreeNode(1), TreeNode(6, TreeNode(4), TreeNode(7))),
                TreeNode(10, None, TreeNode(14, TreeNode(13))))

print(inorder(root, []))      # [1, 3, 4, 6, 7, 8, 10, 13, 14]
print(preorder(root, []))     # [8, 3, 1, 6, 4, 7, 10, 14, 13]
print(postorder(root, []))    # [1, 4, 7, 6, 3, 13, 14, 10, 8]
print(level_order(root))      # [8, 3, 10, 1, 6, 14, 4, 7, 13]
print(height(root))           # 3
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.List;
import java.util.Queue;

public class BinaryTree {
    static class TreeNode {
        int value; TreeNode left, right;
        TreeNode(int value, TreeNode left, TreeNode right) { this.value = value; this.left = left; this.right = right; }
        TreeNode(int value) { this(value, null, null); }
    }

    static void inorder(TreeNode node, List<Integer> out) {      // left, node, right
        if (node == null) return;
        inorder(node.left, out);
        out.add(node.value);
        inorder(node.right, out);
    }

    static void preorder(TreeNode node, List<Integer> out) {     // node, left, right
        if (node == null) return;
        out.add(node.value);
        preorder(node.left, out);
        preorder(node.right, out);
    }

    static void postorder(TreeNode node, List<Integer> out) {    // left, right, node
        if (node == null) return;
        postorder(node.left, out);
        postorder(node.right, out);
        out.add(node.value);
    }

    static List<Integer> levelOrder(TreeNode root) {             // breadth-first, uses a queue
        List<Integer> out = new ArrayList<>();
        Queue<TreeNode> queue = new ArrayDeque<>();
        if (root != null) queue.offer(root);
        while (!queue.isEmpty()) {
            TreeNode node = queue.poll();
            out.add(node.value);
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        return out;
    }

    static int height(TreeNode node) {                           // edges on the longest path down
        return node == null ? -1 : 1 + Math.max(height(node.left), height(node.right));
    }

    public static void main(String[] args) {
        TreeNode root = new TreeNode(8,
            new TreeNode(3, new TreeNode(1), new TreeNode(6, new TreeNode(4), new TreeNode(7))),
            new TreeNode(10, null, new TreeNode(14, new TreeNode(13), null)));

        List<Integer> out = new ArrayList<>();
        inorder(root, out);
        System.out.println(out);                  // [1, 3, 4, 6, 7, 8, 10, 13, 14]
        System.out.println(levelOrder(root));     // [8, 3, 10, 1, 6, 14, 4, 7, 13]
        System.out.println(height(root));         // 3
    }
}
class TreeNode {
  constructor(value, left = null, right = null) {
    this.value = value;
    this.left = left;
    this.right = right;
  }
}

function inorder(node, out = []) {         // left, node, right
  if (node) { inorder(node.left, out); out.push(node.value); inorder(node.right, out); }
  return out;
}

function preorder(node, out = []) {        // node, left, right
  if (node) { out.push(node.value); preorder(node.left, out); preorder(node.right, out); }
  return out;
}

function postorder(node, out = []) {       // left, right, node
  if (node) { postorder(node.left, out); postorder(node.right, out); out.push(node.value); }
  return out;
}

function levelOrder(root) {                // breadth-first, uses a queue
  const out = [], queue = root ? [root] : [];
  for (let head = 0; head < queue.length; head++) {
    const node = queue[head];
    out.push(node.value);
    if (node.left) queue.push(node.left);
    if (node.right) queue.push(node.right);
  }
  return out;
}

const height = node =>                     // edges on the longest path down
  node ? 1 + Math.max(height(node.left), height(node.right)) : -1;

const T = (v, l, r) => new TreeNode(v, l, r);
const root = T(8, T(3, T(1), T(6, T(4), T(7))), T(10, null, T(14, T(13))));

console.log(inorder(root));                // [1, 3, 4, 6, 7, 8, 10, 13, 14]
console.log(preorder(root));               // [8, 3, 1, 6, 4, 7, 10, 14, 13]
console.log(postorder(root));              // [1, 4, 7, 6, 3, 13, 14, 10, 8]
console.log(levelOrder(root));             // [8, 3, 10, 1, 6, 14, 4, 7, 13]
console.log(height(root));                 // 3

Common mistakes

  • Forgetting the base case if node is None: return.
  • Confusing height and depth, or counting nodes where the definition counts edges.
  • Using recursion on a very deep, unbalanced tree and overflowing the call stack.
  • Using an array's shift() as the queue in level-order traversal, which makes it O(n²).

Interview questions

Classic problems built on this topic, with the approach to each. Try them yourself before opening the hint.

Find the maximum depth of a binary tree.

1 + max(depth(left), depth(right)), with an empty tree at depth 0.

Invert (mirror) a binary tree.

Swap the left and right child of every node, recursively.

Check whether two trees are identical.

Both empty, or equal values and recursively identical left and right subtrees.

Return the level-order traversal as a list of levels.

BFS, processing the queue one level (its current length) at a time.

Find the lowest common ancestor of two nodes.

Recurse: if a node sees one target on each side, it is the answer; otherwise pass up whichever side found something.

Frequently asked questions

What is the difference between a binary tree and a binary search tree?

A binary tree only limits each node to two children. A binary search tree adds an ordering rule: everything in the left subtree is smaller than the node and everything in the right subtree is larger.

Which traversal gives sorted output?

In-order traversal of a binary search tree visits the keys in ascending order.

What is the difference between DFS and BFS on a tree?

DFS (pre-, in-, post-order) goes deep along one branch before backtracking and uses a stack. BFS (level-order) visits nodes level by level and uses a queue.
